# Portfolio — File Architecture

```
portfolio/
├── index.html          → البنية الأساسية للصفحة (HTML)
├── css/
│   └── style.css        → كل التنسيقات والألوان (CSS)
├── js/
│   └── script.js         → التفاعلات: القائمة، الكتابة المتحركة، النسخ، الظهور عند التمرير (JavaScript)
├── assets/
│   └── images/            → صورك الشخصية وصور المشاريع
│       └── README.txt
└── README.md              → هذا الملف
```

## لماذا هذا التقسيم؟

- **index.html**: يحتوي فقط على الهيكل والمحتوى (HTML). لا يوجد فيه أي تنسيق أو كود JS مباشر.
- **css/style.css**: كل الألوان والخطوط والتخطيط في مكان واحد، بسهل تعديله دون لمس HTML.
- **js/script.js**: كل السلوك التفاعلي (فتح القائمة على الموبايل، تأثير الكتابة، نسخ البريد، ظهور العناصر عند التمرير).
- **assets/images/**: مكان صورك — بدل ما تكون base64 داخل الكود، الصور ملفات منفصلة يسهل استبدالها.

هذا هو الشكل القياسي (Standard Structure) لأي مشروع HTML/CSS/JS بسيط، ونفس الأسلوب المتبع في معظم قوالب الفرونت اند الاحترافية.

## كيف تشغّلها محلياً

افتح `index.html` مباشرة في المتصفح، أو استخدم أي سيرفر محلي بسيط مثل:
```
npx serve .
```

## كيف ترفعها

ارفع مجلد `portfolio` بالكامل (بكل الملفات والمجلدات الفرعية) على:
- **GitHub Pages**: ادفع المجلد كـ repository، وفعّل Pages من الإعدادات.
- **Netlify Drop**: اسحب المجلد كاملاً إلى https://app.netlify.com/drop

## قبل النشر — عدّل هذه الأشياء

| الملف | ماذا تعدّل |
|---|---|
| `index.html` | الاسم، البريد، روابط GitHub/LinkedIn، نصوص المشاريع |
| `css/style.css` | الألوان (داخل `:root` في الأعلى) إن أردت تغيير الهوية اللونية |
| `assets/images/` | أضف صورتك الشخصية وصور المشاريع (راجع README.txt داخل المجلد) |
